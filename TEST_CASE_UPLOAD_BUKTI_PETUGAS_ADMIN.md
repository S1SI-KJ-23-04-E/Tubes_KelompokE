# Test Case: Upload Bukti Pelaporan - Role Petugas / Admin

| Scenario ID | Case ID | Test Scenario | Type | Test Case | Pre Condition | Steps | Expected Result | Status |
|-------------|---------|---------------|------|-----------|---------------|-------|-----------------|--------|
| SC-01 | TC-01 | Upload bukti berhasil oleh Petugas | Fungsional | Petugas di kecamatan yang sama dengan laporan dapat membuka modal upload bukti dan mengunggah foto beserta catatan | 1. Akun sudah login sebagai `petugas` di kecamatan yang sama dengan laporan. 2. Status laporan `verified` atau `in_progress`. 3. Laporan sudah terdaftar di sistem. | 1. Buka halaman detail laporan. 2. Pastikan tombol `Upload Bukti` tampil. 3. Klik tombol `Upload Bukti`. 4. Pilih file gambar valid (JPG/PNG). 5. Isi kolom keterangan bukti. 6. Klik `Kirim Bukti`. | - Modal upload tampil. - Tombol `Upload Bukti` aktif. - File preview muncul. - Setelah submit, status laporan berubah menjadi `done`/`selesai`. - Pesan sukses `Bukti berhasil dikirim...` tampil. - Foto bukti dan keterangan muncul di detail laporan. | Belum diuji |
| SC-01 | TC-02 | Upload bukti berhasil oleh Admin Kecamatan / Super Admin | Fungsional | Admin kecamatan atau super admin dapat mengunggah bukti untuk laporan di kecamatan yang sama | 1. Akun sudah login sebagai `kecamatan` atau `super_admin`. 2. Laporan berada di kecamatan yang sama (untuk `kecamatan`) atau global (untuk `super_admin`). 3. Status laporan `verified` atau `in_progress`. | 1. Buka halaman detail laporan. 2. Verifikasi tombol `Upload Bukti` tampil. 3. Klik tombol dan unggah file gambar. 4. Masukkan catatan bukti. 5. Submit. | - Upload berhasil tanpa error. - Status laporan update ke `done`. - Bukti foto tersimpan dan ditampilkan di bagian `Misi Selesai` atau `Bukti penyelesaian`. | Belum diuji |
| SC-02 | TC-03 | Upload bukti tidak tersedia untuk laporan kecamatan lain | Keamanan | Petugas atau admin tidak dapat mengunggah bukti pada laporan yang bukan dari kecamatan mereka | 1. Akun `petugas` atau `kecamatan` login. 2. Laporan berasal dari kecamatan berbeda. | 1. Buka halaman detail laporan berbeda kecamatan. 2. Cek keberadaan tombol `Upload Bukti`. 3. Jika API dipanggil manual, pastikan akses ditolak. | - Tombol `Upload Bukti` tidak tampil. - Jika memaksa panggilan API, sistem menolak dengan pesan `Anda hanya bisa memperbarui laporan di kecamatan Anda sendiri.` atau `403`. | Belum diuji |
| SC-03 | TC-04 | Upload bukti gagal tanpa file | Validasi | Petugas/admin mencoba submit tanpa memilih file | 1. Akun petugas/admin login dan berada pada laporan berstatus `verified` atau `in_progress`. | 1. Buka modal `Upload Bukti`. 2. Jangan pilih file. 3. Isi keterangan. 4. Klik `Kirim Bukti`. | - Tombol submit `Kirim Bukti` dalam kondisi disabled saat belum ada file. - Tidak terjadi pengiriman data. | Belum diuji |
| SC-04 | TC-05 | Upload bukti gagal saat file jenis lain dipilih | Validasi | Upload hanya menerima gambar, file non-image seharusnya tidak dapat dipilih | 1. Modal upload dibuka. | 1. Klik area pilih file. 2. Coba pilih file non-gambar (misalnya PDF). | - File non-gambar tidak muncul di dialog karena `accept="image/*"`. - Jika browser tetap memilih file, upload kemungkinan gagal di backend. | Belum diuji |

> Catatan: Test case dikembangkan berdasarkan implementasi `Front-End/src/components/UploadBuktiModal.jsx`, `Front-End/src/pages/LaporanDetail.jsx`, dan `Front-End/src/services/laporanService.js`.
